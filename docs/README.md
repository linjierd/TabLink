# TabLink historical release records

**English (Singapore)** | [简体中文](README.zh-CN.md)

This directory keeps release notes and verification records for earlier TabLink versions so the repository root stays focused on the current release. These files are historical evidence: they describe the exact builds, devices and test boundaries recorded at that time, and do not replace current-version verification.

The 0.7.0–0.8.8 archive is preserved in its original Chinese unless a language-specific file is present.

The current documents remain at the repository root:

- [TabLink 0.8.9 Preview 1 release notes](../RELEASE-0.8.9.md)
- [TabLink 0.8.9 Preview 1 verification record](../VERIFICATION-0.8.9.md)
