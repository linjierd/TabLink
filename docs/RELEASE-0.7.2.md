# TabLink 0.7.2：副屏回收重试

Windows 电脑端 0.7.2；安卓 APK 保持 0.7.1，无需重新安装。

## 修复的问题

停止连接时，如果 Windows 暂时拒绝收回虚拟屏，旧版本会丢失可重试的清理状态，并保留内存中的屏幕占用。主连接再次连接会报“此设备会话已经拥有独立副屏”；额外原生设备和浏览器也可能留下无法重新分配的占用。

现在由统一的屏幕分配器保留待清理记录。每次连接前，先重试已经停止的会话；确认清理成功后才移除占用。独立守护进程已经回收，或该目标明确交给新会话时，旧清理会安全结束。持续失败或所有权记录不可读时，目标和显示源继续保留，不能被另一台设备抢占；其他未被占用的目标仍可连接。

屏幕准备期间，已创建 guard 的回滚如果失败，也会保留并在下一次连接前重试。Guard 构造本身抛异常的回滚仍走既有保护路径，不在本次新增重试保证范围内。

## 使用

运行完整目录中的 `TabLink.exe`。本次为电脑端更新，继续使用原来的 Android 0.7.1 客户端。遇到临时回收失败时，状态栏会提示再次连接自动重试；若 Windows 或所有权记录仍不可用，会显示等待安全回收，不会误接管其他屏幕。

本版仅修复 review 第一项；编码、画质、帧率、驱动与其他 review 项目未作调整。构建和验证证据见 `VERIFICATION-0.7.2.md`。
