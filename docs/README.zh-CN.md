# TabLink 历史发布记录

[English (Singapore)](README.md) | **简体中文**

本目录统一保存 TabLink 旧版本的发布说明和验证记录，让仓库根目录只突出当前版本。这些文件是历史证据，只描述当时记录的特定构建、设备和测试边界，不能替代当前版本的验证。

0.7.0–0.8.8 的历史文件按原始中文内容保留；只有明确带语言后缀的文件才表示独立语言版本。

当前版本文档继续保留在仓库根目录：

- [TabLink 0.8.9 Preview 1 发布说明](../RELEASE-0.8.9.zh-CN.md)
- [TabLink 0.8.9 Preview 1 验证记录](../VERIFICATION-0.8.9.zh-CN.md)
