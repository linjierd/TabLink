# TabLink 0.7.3：诊断保存失败不再中断副屏

Windows 电脑端 0.7.3，Android 客户端保持 0.7.1，无需重新安装 APK。

## 修复

旧版把定期写入诊断文件放在连接监测的异常处理范围内。诊断文件被占用、目录不可写或写入失败时，原本正常的主连接也会被停止。

新版将诊断快照生成、JSON 序列化和存储错误与连接生命周期隔离。包括快照中的显示器查询失败，均不再作为连接故障处理。同一诊断文件连续失败只在连接记录中提示一次；成功保存后，如发生新的失败，可以再次提示。不会弹出错误框或改写连接状态栏。

诊断数据先写到同目录的临时文件，完成后再替换目标；失败时保留上一份有效记录。文件时间可能因此保持旧值，读取工具不能把旧记录视为当前连接状态。

## 数据位置

从本版起，运行诊断保存在 `%LOCALAPPDATA%\TabLink\diagnostics`，与可放在 OneDrive 的程序目录分开。程序目录内的旧 `diagnostics` 仅保留历史数据，不再更新。测量工具已更新默认路径，并忽略过期或进程身份不匹配的健康记录。

显示租约、所有权标记、排除规则和其他影响连接安全的关键记录仍保留原来的严格保存及错误处理；本次仅隔离可选诊断数据。USB 探测命令如果无法保存唯一的结果文件，仍返回失败退出码。

0.7.2 的副屏回收重试修复继续保留。本次未调整编码、画质、帧率、驱动和客户端。
