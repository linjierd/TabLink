# TabLink 0.8.0：正式版自动更新

Windows 电脑端和 Android 客户端统一升级为 0.8.0。此版本增加签名稳定频道、后台下载、安装前二次校验、Windows 事务回滚，以及 Android 系统安装接入。

Windows 不会为更新中断正在使用的副屏。更新下载完成后，如果主连接、多设备连接或浏览器副屏仍在运行，程序会继续保持当前画面；最后一个会话停止且程序空闲后，等待 10 秒再自动重启安装。正式运行目录固定为 `%ProgramFiles%\TabLink`，独立更新器与事务目录位于受保护的 `%ProgramData%\TabLink`，可以安全替换包括更新器自身在内的完整目录。新版启动健康检查失败或目录切换失败时，会保留或恢复旧目录并重新启动旧版；桌面与 OneDrive 目录作为完整离线镜像和快捷入口保留。

Android 在回到前台时立即检查，之后每 6 小时检查一次。投屏期间不下载或安装；停止投屏后自动下载。安装使用 Android `PackageInstaller`，满足系统条件时请求自动完成；系统返回需要用户操作时，会打开标准安装确认页。APK 的签名、包名、版本号、大小与 SHA-256 都必须与签名清单一致。

浏览器客户端随电脑端更新。iOS / iPadOS 与 HarmonyOS NEXT 原生源码也接入同一稳定频道，但正式安装必须分别由 App Store 与 AppGallery 完成；当前仍没有已签名 IPA / HAP 或商店上架记录，因此 0.8.0 公共清单只发布已经实际构建和验证的平台。

完整信任模型、发布命令、下载站目录和平台限制见 `AUTO-UPDATE.md`。构建、签名、下载站与设备验证结果见 `VERIFICATION-0.8.0.md`。
